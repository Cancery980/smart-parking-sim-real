## 梁可最短接线入口

先完整解压演示包、双击 ParkingDemo.exe，看默认仿真页 `http://127.0.0.1:8766/`。需要改代码时按[新手指引](梁可从这里开始.md)准备Python源码环境，保留无参 `Planner` 类的 `plan(context, request)` 和 `find_vehicle(context, request)` 两个入口。新建 `liang_planner.py` 后执行：

```powershell
.\.venv\Scripts\python.exe scripts/check_plugin.py --planner liang_planner:Planner
powershell -ExecutionPolicy Bypass -File .\start.ps1 -Planner liang_planner:Planner
```

不要修改胡模块的地图、视觉或会话来迁就接口。自己的算法接入后，运行指向该模块的E01—E08和配对实验，保留单独的结果目录。
